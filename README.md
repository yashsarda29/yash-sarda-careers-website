# Yash Sarda: Career Guidance

Single-page website for 1:1 career guidance sessions. Open `index.html` in a browser, or host it free on GitHub Pages.

## Editing
- **Sessions:** the `STAGES` list near the bottom of `index.html`
- **"Where are you stuck?" answers:** the `PAINS` list right below it
- **WhatsApp number / LinkedIn link:** `WHATSAPP_NUMBER` and `LINKEDIN_URL` near the top of `<body>`
- **Photo:** add `yash.jpg` to this folder and replace the `YS` placeholder in the About card with `<img src="yash.jpg" alt="Yash Sarda">`
